# MILAAN 3-Minute Hackathon Demo Script

## 0:00–0:20 — Opening
"This is MILAAN — AI-Powered GST Invoice Reconciliation and Follow-up Agent. It helps identify missing or uncertain invoice records and turns them into trackable cases."

## 0:20–0:50 — Dashboard
"We start with five synthetic invoices. Three are matched, two need review, and the potential discrepancy amount is ₹3,600. These metrics are computed from underlying records, not hardcoded."

## 0:50–1:20 — Invoice Workspace
"I can upload a PDF/image for manual review and add invoices manually with GST arithmetic validation. Here are invoice filters by status and supplier."

## 1:20–1:55 — Agent Workspace
"Now I run MILAAN Agent on INV-103. The activity panel shows each step: request received, records fetched, reconciliation, discrepancy classification, recommendation, and waiting for approval. This is deterministic tool orchestration for reliable demo behavior."

## 1:55–2:30 — Case + Follow-up Approval
"Opening the case, I review the drafted supplier message and approve demo follow-up. MILAAN records the event and clearly states that no real message was sent."

## 2:30–2:50 — Later Verification
"Next I import later statement CSV data and verify the case. Only now does status move to 'Verified in Demo Data'. Follow-up simulation alone never marks recovery."

## 2:50–3:00 — Close
"MILAAN separates source data, deterministic calculations, recommendations, approvals, and verified outcomes. It is designed for responsible financial workflows and transparent auditability."
